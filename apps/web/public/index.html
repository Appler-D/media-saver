高清需要登录？配置 Cookie

把目标平台的 Cookie 写入 ~/.media-saver/cookies.json （Windows 为 %USERPROFILE%\.media-saver\cookies.json）： 

{
  "bilibili": "SESSDATA=...; bili_jct=...;",
  "xiaohongshu": "a1=...; web_session=...;"
}

Cookie 只在请求对应平台时使用，不会上传到任何第三方。抖音解析使用本机浏览器的登录态，无需写入 Cookie。
